# shell

Planned home of the AOS shell and first-party apps: top bar, dock, launcher, notifications,
control centre, Settings. They are Xefy apps written in Prismio that run as Wayland clients
of KWin.

This directory is empty. Work here starts when Xefy has a Linux Wayland embedder with
layer-shell support (see `docs/PLAN.md`, phase P2, and `docs/AOS_PLAN.md` in the Xefy
repository).
